1. Input Text

The pipeline accepts a raw string representing a social post, review, or feedback. This input typically contains noisy elements like URLs, username tags, hashtags, emojis, punctuation, and mixed capitalizations.

2. Regex Cleaning

Using Python regular expressions, we strip URLs (https://...), username mentions (@user), hashtag symbols, and non-ASCII character blocks/emojis. We then convert all remaining characters to lowercase to prevent casing duplicates (e.g., "Great" and "great").

3. Tokenization

The string is broken down into a sequence of individual words or symbols (called tokens) using NLTK's word_tokenize parser, facilitating word-level processing.

4. Stopword Removal

High-frequency words like "is", "the", "and", "at" that carry little to no emotional sentiment are filtered out using the Natural Language Toolkit (NLTK) English stopwords dictionary.

5. Porter Stemming

We apply the Porter Stemmer algorithm to reduce each token to its core root form. For example, "happiest", "happier", and "happy" are all mapped to the stem root happi, grouping words with the same core semantic meaning.

6. TF-IDF Vectorization

Term Frequency-Inverse Document Frequency. Transforms the sequence of processed tokens into numerical arrays. It measures how frequent a word is in a single text document relative to how common or rare it is across the entire training dataset.

7. Logistic Regression

A supervised Machine Learning classifier. It uses the numeric TF-IDF vectors to fit a linear mathematical decision boundary, estimating log-odds probabilities to determine which sentiment category a text belongs to.

8. Final Prediction

The category (Positive, Neutral, or Negative) with the highest predicted probability is returned. The probability score is converted to a confidence percentage and outputted alongside the corresponding category emoji.
